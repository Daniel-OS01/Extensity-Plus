💡 What: Added a placeholder and an `aria-label` to the search input box in `index.html`, and marked the adjacent visual search icon with `aria-hidden="true"`.

🎯 Why: The search input lacked a placeholder or accessible label, making it difficult for screen reader users to identify the purpose of the input field. Additionally, the decorative FontAwesome icon could be redundantly or confusingly announced.

📸 Before/After: The search bar now displays "Search extensions" visually and is announced as "Search extensions" to screen readers.

♿ Accessibility:
- Added `aria-label="Search extensions"` for screen readers.
- Added `placeholder="Search extensions"` for visual guidance.
- Added `aria-hidden="true"` to the decorative icon to prevent unnecessary screen reader output.
