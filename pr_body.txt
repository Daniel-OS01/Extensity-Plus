💡 **What:** Added a placeholder ("Search extensions and apps...") and an `aria-label` to the main search box in `index.html`. Also explicitly hid the decorative search icon using `aria-hidden="true"`.

🎯 **Why:** Standalone inputs without explicit `<label>` tags must be made accessible to screen readers, and adding a `placeholder` gives a strong visual affordance about the input's purpose before typing. Hiding the decorative icon prevents screen readers from reading it as confusing extra text.

📸 **Before/After:** The search box now clearly displays "Search extensions and apps..." when empty, improving clarity.

♿ **Accessibility:**
- Added `aria-label="Search extensions and apps"` to the search `<input>`.
- Added `aria-hidden="true"` to the decorative `<i class="fa fa-search"></i>` icon.
