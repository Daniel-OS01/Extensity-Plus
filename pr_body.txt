💡 **What**:
Wrapped icon-only `<i>` tags for "Options" (in `index.html`) and "Delete profile" (in `profiles.html`) with `<button>` elements. I used an inline style reset (`style="background:none; border:none; padding:0; cursor:pointer; color:inherit;"`) to perfectly maintain the existing design system appearance without needing custom CSS.

🎯 **Why**:
Icons lacking semantic `<button>` wrappers can't be focused via the keyboard and aren't properly announced by screen readers as actionable elements.

♿ **Accessibility**:
- Added `type="button"` to ensure semantic correctness.
- Added descriptive `aria-label`s to the new wrappers ("Options" and "Delete this profile").
- Set `aria-hidden="true"` on the decorative font-awesome icons so screen readers announce the label rather than a raw icon glyph.
- Retained previous Knockout data bindings to ensure existing functional click interactions remained unharmed and properly triggered.
