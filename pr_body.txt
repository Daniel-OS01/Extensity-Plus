💡 What: Optimized `runToggleAll` and `runApplyProfile` in `js/background.js` by combining array `.filter()` and `.map()` iterations into a single `for` loop pass, and refactored O(N) `.indexOf()` lookups with O(1) `Set.prototype.has()` lookup checks for array containment.
🎯 Why: Iterating over and creating intermediate array clones creates unnecessary CPU memory overhead in long-lived background execution loops. Furthermore, repeated $O(N)$ lookup lookups inside an iteration pass lead to $O(N^2)$ algorithmic time complexity.
📊 Impact: Considerably faster overall execution time for profile applications and toggling, reducing intermediate array allocations.
🔬 Measurement: Verify identical runtime functionality while tracing decreased CPU profiling usage in DevTools during "Apply Profile" and "Toggle All" actions.
